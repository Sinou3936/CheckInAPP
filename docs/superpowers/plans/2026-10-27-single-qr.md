# QR 단일화 + 최소 체류 시간 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 카운터에 QR 을 하나만 띄우고, 등원인지 하원인지는 서버가 회원 상태에서 판정하며, 등원 직후의 재스캔은 시설이 설정한 최소 체류 시간으로 막는다.

**Architecture:** `QrTokenService` 가 토큰 하나를 돌린다. 확인 세션은 종류를 담지 않고, 대신 서버가 판정이 허용한 행동마다 **불투명한 1회용 action id** 를 그 세션에 발급한다. 페이지는 판정을 먼저 보여주고 학생이 누른 action id 를 되돌려주며, 서버는 쓰기 시점에 **다시 판정해서** 그 행동이 여전히 허용되는지 확인한 뒤에만 기록한다. 최소 체류 시간은 `app_state` 에 분 단위로 저장하고 요청마다 읽는다.

**Tech Stack:** Flutter Desktop(Windows), Dart, `sqflite_common_ffi`, `shelf` + `shelf_router`, `qr_flutter`.

**Spec:** `docs/superpowers/specs/2026-10-27-single-qr-design.md` (2026-10-27 승인). 권위 스펙은 `2026-09-18-checkin-app-design.md` 이고 Task 1 이 그것을 개정한다. 둘이 충돌하면 권위 스펙이 이긴다.

## Global Constraints

- 폴더명 `checkInApp` ≠ 패키지명 `checkin_app`. import 는 항상 `package:checkin_app/...`.
- 데스크톱 SQLite 는 `sqflite_common_ffi`. 테스트 DB 는 `test/helpers/test_db.dart` 를 쓴다 (새로 만들지 말 것).
- 위젯 테스트는 `test/helpers/widget_test_helpers.dart` 의 `pumpUntil`·`shown`·`absent`·`inRow` 를 쓴다. 맨 `pumpAndSettle()` 은 대기 중인 DB 응답을 몰라 타임아웃하고, 맨 `pump()` 는 sqflite 의 10초 락 타이머를 남겨 "A Timer is still pending" 이 된다.
- `find.text` 는 `EditableText` 도 잡는다. 목록 단정은 `inRow(...)` 로 한정하고, 저장 뒤에는 다이얼로그가 닫혔는지까지 본다.
- **외부 서버 없음. 서버는 앱과 한 프로세스. QR 토큰은 주기적으로 갱신된다 (30초 수명 + 10초 유예). 회원 1명은 반 1개.**
- 체크인 페이지는 CDN·웹폰트·원격 이미지·절대 주소를 쓰지 않는다. 자체 완결 HTML 한 장이다.
- 알림은 **새로 기록된 경우에만** 낸다. 재스캔·보정·차단은 알림을 내지 않는다.
- 최소 체류 시간 기본값 **30분**, 하한 **1분**, 상한 **12시간 미만**(하원 창보다 작아야 한다).
- 커밋 메시지는 한글, 타입 접두사(`feat:`/`fix:`/`docs:`/`refactor:`)만 영어. `main` 에서 직접 작업한다.
- 각 태스크 커밋 전에 `dart format lib test`, `flutter analyze`(No issues), `flutter test`(전부 통과)를 **Windows 에서 실제로 돌려** 확인한다. `flutter run` 은 돌리지 않는다.

## Review Focus

- **`app_state` 의 최소 체류 시간 값이 깨져 있을 때** (비숫자, 0, 음수, 12시간 이상) 읽기가 예외를 던지거나 하원을 영구히 막으면 시설이 복구할 길이 없다 → 기본값으로 떨어져야 한다. (Task 2)
- **같은 action id 로 두 번 쓰기 요청** 이 들어오면 학부모에게 알림이 두 번 간다 → 두 번째는 거절돼야 한다. (Task 6)
- **다른 확인 세션이 발급한 action id** 를 가져다 쓰는 경로는 위조다 → 세션에 묶여 있어야 한다. (Task 4·6)
- **자정 경계**: 오늘 행이 없고 어제 열린 세션이 창 안에 남은 상태(선택), 오늘 행이 열린 채 12시간이 지난 상태(창 지남). 둘을 섞으면 거짓 하원 알림이 나간다. (Task 5)
- **설정을 바꾼 직후의 요청** 이 옛 값을 쓰면 시설은 앱을 다시 띄워야 한다고 생각한다 → 다음 요청부터 새 값이어야 한다. (Task 6)
